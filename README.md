# Healthcare CRM SQL Analysis

> Understanding patient engagement, retention and revenue through healthcare CRM analytics using MySQL.

---

## Overview

This project explores healthcare data from a Customer Relationship Management (CRM) perspective.

Rather than analysing hospital operations alone, the focus is on understanding patient behaviour, engagement, revenue generation and long-term patient value.

Using SQL, the project answers business questions that could support healthcare managers, clinic administrators and CRM teams when making operational and strategic decisions.

---

## Objectives

This project demonstrates how SQL can be used to:

- Analyse patient engagement
- Measure patient retention
- Calculate patient lifetime value
- Segment patients based on spending
- Evaluate doctor performance
- Analyse revenue generation
- Support healthcare CRM decision-making

---

## Executive Summary

Analysis of the healthcare CRM database identified several important business insights.

Patients varied considerably in both appointment frequency and revenue contribution. Segmentation analysis showed opportunities to identify high-value patients, while billing analysis highlighted payment trends that could support financial planning.

By combining appointments, treatments and billing information, SQL was used to create reusable reports suitable for healthcare management and CRM teams.
